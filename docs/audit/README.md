## 审计约束

- 每条结论必须引用真实文件、类、函数或配置；不确定的内容明确标记，禁止猜测。
- 审计阶段禁止修改任何业务源码，只允许安装、运行测试与静态检查、阅读源码、在本目录写文档。
- 人工批准审计文档后才能进入架构修订（`PROJECT_SPEC.md` §17.2）。
